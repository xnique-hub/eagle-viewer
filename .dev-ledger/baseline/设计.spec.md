# 设计规格

## DES-001：逐级缩放与导航缩略图

对应 REQ-001、TECH-001、CON-001。eagle-viewer.html 中 lbScale 为 null 时使用原适屏/适宽布局；手动缩放通过 .lb-viewport 滚动容器与舞台宽高实现。每级乘 1.25 或 0.8，比例限制为原始尺寸的 0.05～16 倍。updateLBMap 使用图像和可视区域矩形计算缩略图范围框，点击概览可定位。切图、关闭及模式切换清除手动状态。验证：TEST-001、TEST-004。

## DES-002：双向拖动

对应 REQ-002、TECH-001、CON-002。installLBDrag 为大图与缩略图安装 Pointer Events；大图拖动反向改变滚动偏移，范围框按原图显示尺寸与缩略图尺寸比例换算偏移。getLBScrollArea 兼容手动缩放与适宽模式；pointer capture 保持越界拖动，endLBDrag 在释放、取消、切图、关闭、窗口变化时清理。滚动及拖动均刷新范围框。验证：TEST-002、TEST-004。

## DES-003：0 键复位

对应 REQ-003、CON-001。lbKey 在非输入控件且存在手动比例时处理 0，调用 resetLBScale 和 applyLBZoom，保留 lbFitWidth，滚动回顶部并更新概览。验证：TEST-003、TEST-004。
