# 需求规格

归档日期：2026-10-22（Asia/Shanghai）。首次建立账本，仅记录本次可见对话的已确认需求；原有功能背景见 AGENTS.md，不追溯推定批准记录。

## 功能需求

- REQ-001（已确认、已实现）：大图中按 ↑ / ↓ 或工具栏按钮逐级放大、缩小；缩放时显示缩略图及当前可见范围。验收：缩放改变图像尺寸，范围框与可见区域对应。来源：本次用户请求。
- REQ-002（已确认、已实现）：图像超出窗口时可按鼠标左键拖动；拖动缩略图可视框也能移动大图，两者同步。验收：移动方向正确，松开鼠标结束拖动；适宽长图同样适用。来源：本次用户请求。
- REQ-003（已确认、已实现）：手动放大或缩小时按 0 恢复原先适屏或适宽模式。验收：保留原模式选择，退出手动缩放；输入框输入 0 不触发复位。来源：本次用户请求。

## 技术路线与约束

- TECH-001：保持单文件原生 HTML/CSS/JavaScript；Pointer Events 捕获拖动，滚动位置驱动可视框。依据：项目 AGENTS.md 与本次实现。
- CON-001：避免框架迁移及无关重构；仅局部修改 eagle-viewer.html。来源：AGENTS.md。
- CON-002：真实目录选择流程需支持 File System Access API 的 Chrome / Edge；浏览器视觉与实际目录联调尚未验证。来源：AGENTS.md 与本次验证边界。
